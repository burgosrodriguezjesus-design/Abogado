# Grupo Mediando — Propuesta de web

Maqueta de página web para un despacho de mediación, extranjería y servicios jurídicos en Málaga,
inspirada en los contenidos de grupomediando.com.

Abre `index.html` en cualquier navegador; no requiere instalación.

## Pendiente de personalizar con datos reales
- Dirección, teléfono, WhatsApp y email (ahora son de ejemplo)
- Cifras del despacho (años, clientes, % de acuerdos)
- Testimonios (ahora son de ejemplo)
- Envío real de los formularios y textos legales (aviso legal, privacidad, cookies)
